# FloraDex

UTS 32513 Advanced Data Analytics — Assessment 2

## Project overview

FloraDex is a flower image classification project that explores the use of transfer learning to identify flower species from photographs.

## Project structure

- `floradex_a2.ipynb` — main machine learning notebook
- `implementation_log.md` — development, learning and decision log
- `data/` — dataset documentation
- `results/` — saved evaluation outputs and figures
- `docs/` — assessment-related documentation
